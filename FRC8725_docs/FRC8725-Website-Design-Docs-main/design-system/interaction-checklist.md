# 互動驗收清單

本清單適用於 Team 8725 的所有網站與 Web App。每次新增或修改元件時，至少完成相關項目，並確認設計符合唯一正式規範 [`design-system-guide.md`](../design-system-guide.md)。

## 規範與視覺一致性

- [ ] 使用共用 design tokens，沒有為單一產品建立重複或無語意的樣式。
- [ ] CSS 中的顏色值只定義在 token／變數層；選擇器一律以 `var(...)` 引用顏色。
- [ ] 所有一般介面文字使用 `var(--font-family)`。
- [ ] 領域專屬模式沒有被誤寫成所有產品的通則。
- [ ] 除明確的圓形物件外，長方形元件的圓角不超過自身最短邊的 1/3。
- [ ] 一般 button、input、card、panel、list row、toast 與 dialog 未使用膠囊圓角。
- [ ] 圓形與膠囊外形只用於規範允許且具明確語意的元件。

## 一般狀態

- [ ] Default 狀態能辨識用途與可互動性。
- [ ] Hover 不造成尺寸或位置改變。
- [ ] Active 提供立即回饋。
- [ ] Focus-visible 清楚可見且不被裁切。
- [ ] Disabled 仍可閱讀，並避免觸發事件。
- [ ] Loading 固定元件寬度，避免重複提交。
- [ ] Success 說明完成的物件與動作。
- [ ] Error 說明失敗結果與下一步。

## 鍵盤

- [ ] Tab 順序符合閱讀順序。
- [ ] Enter 與 Space 可操作自訂按鈕。
- [ ] Escape 可關閉 modal 或暫時浮層。
- [ ] 分頁可使用左右方向鍵切換。
- [ ] 關閉 modal 後焦點回到觸發控制。

## Pointer 與觸控

- [ ] 手機觸控目標至少 44×44 px。
- [ ] 整列點擊不會攔截列內按鈕。
- [ ] hover 資訊也能透過 focus 取得。
- [ ] 捲動區不會意外帶動整頁。

## 版面穩定

- [ ] 搜尋結果改變時，搜尋輸入與面板外框不移動。
- [ ] Tabs、views 或資料來源切換時，主要內容區不出現不必要跳動。
- [ ] loading、empty、error 不改變主要容器尺寸。
- [ ] 數量更新時，使用 tabular numbers 避免欄位跳動。

## 響應式

- [ ] 1440、1024、828、768、390 與 320 px 寬度可完成任務。
- [ ] 200% 縮放時沒有橫向頁面捲軸。
- [ ] 核心資訊完整可取得；省略文字時有方法讀取全文。
- [ ] 操作按鈕在窄螢幕仍靠右或移到明確的操作列。

## 權限與危險操作

- [ ] 無權限的操作不顯示。
- [ ] 前端隱藏不取代後端授權規則。
- [ ] 危險操作顯示對象、影響範圍與是否可復原。
- [ ] 產品的權限、數量與狀態限制均有清楚訊息。

## 無障礙

- [ ] 一般文字符合 4.5:1 對比。
- [ ] icon-only 按鈕有 `aria-label`。
- [ ] 圖片有正確 `alt`。
- [ ] 表單錯誤與欄位建立 `aria-describedby` 關聯。
- [ ] 動態訊息使用合適的 live region。
- [ ] `prefers-reduced-motion` 關閉非必要動畫。
