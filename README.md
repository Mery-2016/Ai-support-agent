# TashkentBlinds.AI — Жалюзи и Рулонные шторы в Ташкенте

Интеллектуальный веб-сервис и лендинг с AI-консультантом для подбора и расчета стоимости жалюзи и рулонных штор в Ташкенте (все 12 районов города).

---

## 🌟 Основные возможности

1. **Экспресс-калькулятор стоимости в сумах (UZS):**
   - Расчет нормативной площади изделия: $S = \max(1.0, W \times H)$ м².
   - 6 актуальных линеек продукции (День-Ночь Зебра, Blackout 100%, Screen светофильтр, Горизонтальные алюминиевые, Вертикальные тканевые, Плиссе и Римские).
   - Автоматический расчет монтажа (0 сум при заказе от 3 окон).
   - Быстрый перенос расчета в чат с ИИ-консультантом.

2. **AI Support Agent (Google Gemini 3.5 / 3.6 / 3.8):**
   - Архитектура **Mandatory BYOK (Bring Your Own Key)** через прямой Google AI Studio API.
   - Поддержка современных ключей (`AQ.A...`), классических (`AIza...`) и демонстрационного режима.
   - Экспертная база знаний рынка Ташкента: монтаж на рамы Akfa / Imzo / Engelberg без сверления, защита от чилли +45°C, фиксация на откидных окнах при проветривании, оплата через Click / Payme / Didox, уход без машинной стирки, моторизация Dooya / Somfy и интеграция с Яндекс Алисой.
   - Двухуровневый триаж: мгновенный автономный ответ или оперативная эскалация к живому менеджеру.

3. **Интерактивный раздел FAQ:**
   - 8 подробных карточек с реальными вопросами и ответами для покупателей Ташкента.
   - Кнопка «Спросить у ИИ →» на каждой карточке для мгновенного перехода в диалог.

4. **Дизайн-система Team 8725:**
   - Строгая иерархия стилей: `fonts.css` $\rightarrow$ `tokens.css` $\rightarrow$ `base.css` $\rightarrow$ `app.css`.
   - 100% семантических токенов (`var(--color-*)`, 0 hardcoded hex/rgb).
   - Адаптивные контрольные точки: `1100px`, `900px`, `768px`, `480px`.
   - Защищенный HTTP-сервер Node.js (Directory Traversal protection, XSS escaping).

---

## 🚀 Запуск и тестирование

### Запуск веб-сервера
```powershell
node server.js
```
Сайт будет доступен по адресу: **http://localhost:8080/**

### Запуск тестов
```powershell
node test_implementation.js
```
Проверяет 117 критериев качества, безопасности, точности математических формул и классификации интентов.
