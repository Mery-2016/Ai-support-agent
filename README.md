# COMBO.UZ — Жалюзи и Рулонные шторы в Узбекистане

Интеллектуальная система AI-продаж, управления базой знаний (100 Q&A RU/UZ) и CRM входящих заявок для компании **COMBO.UZ**.

---

## 🌟 Основные компоненты системы

### 1. 💬 Тестовый стенд AI-чата продаж (`test_sales_chat.html`)
- URL: **http://localhost:8080/test_sales_chat.html**
- **Двуязычность:** полноценная работа на русском (🇷🇺) и узбекском (🇺🇿) языках с автоопределением языка реплик.
- **Отработка возражений:** встроенные сценарии для сложных клиентов («Дорого!», «Я подумаю», «У конкурентов дешевле», «Сделайте скидку», «Боюсь сверлить окна Akfa» и др.).
- **Воронка продаж:** автоматическое выявление потребности (комната, сторона солнца), подбор подходящей модели штор, расчет площади и стоимости в сумах (UZS).
- **Сбор лидов:** при готовности заказать агент собирает имя, телефон (+998), район Ташкента, модель и размеры, формируя готовую заявку.
- **Панель диагностики (Inspector):** мониторинг текущего этапа воронки, извлеченных данных заказа и использованной статьи базы знаний в реальном времени.

### 2. ⚙️ Панель администратора (`admin.html`)
- URL: **http://localhost:8080/admin.html**
- **Управление базой знаний (100 Q&A):**
  - Просмотр, поиск и фильтрация по 6 категориям (Модели, Возражения, Замеры, Цены, Сроки/Гарантии, Уход).
  - Подсветка статей, требующих заполнения условий компании (`[Требуется заполнение администратором]`).
  - Добавление и редактирование вопросов и ответов на русском и узбекском языках прямо в браузере.
  - Удаление устаревших записей с сохранением в `data/knowledge_base.json`.
- **Журнал заявок (Leads CRM):**
  - Таблица поступивших заявок от клиентов (с сайта и AI-чата).
  - Смена статусов: `NEW` (Новая), `IN_PROGRESS` (В работе), `COMPLETED` (Выполнена), `CANCELLED` (Отменена).
  - Кнопки быстрого звонка и перехода в Telegram.

### 3. 📚 База знаний 100 Q&A (`data/knowledge_base.json`)
Охватывает все ключевые темы и линейки штор:
1. **Модели (41 вопрос):** «День-Ночь» (Зебра), Blackout 100%, Плиссе, Honeycomb (сотовые), Double (двойные), Тюлевые шторы (жалюзи-тюль), Римские шторы, Горизонтальные алюминиевые, Вертикальные тканевые.
2. **Замеры и монтаж (15 вопросов):** бесплатный выезд замерщика, монтаж без сверления на Akfa/Imzo со скотчем 3M, направляющие и магниты при проветривании, арочные и панорамные окна.
3. **Цены и скидки (12 вопросов):** расчет стоимости за м², прогрессивные скидки на объем, способы оплаты (Click, Payme, р/с).
4. **Сроки, доставка и гарантия (12 вопросов):** сроки изготовления, доставка по Ташкенту и регионам Узбекистана, гарантийные обязательства.
5. **Качество и чилля +45°C (8 вопросов):** устойчивость к жаре, тефлоновые пропитки, уход без стирки в машинке, безопасность для детей.
6. **Отработка возражений (12 вопросов/сценариев):** «Дорого», «Я подумаю», «У конкурентов дешевле», «Можно скидку?», «Боюсь испортить окна», «Вдруг ткань выгорит», «А если не подойдет размер», «Нужно посоветоваться с семьей».

### 4. 🌐 Основной интерактивный лендинг (`index.html`)
- URL: **http://localhost:8080/**
- Экспресс-калькулятор стоимости в сумах (UZS) с порогом $S_{min} = 1.0\text{ м}^2$.
- Интеграция с Google AI Studio (Gemini 3.5 / 3.6 / 3.8 Pro BYOK).
- Каталог 6 популярных систем, интерактивный FAQ и охват всех 12 районов г. Ташкента.

## 🔌 Серверные REST API Endpoints (`server.js`)

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/api/knowledge-base` | Получение полного массива 100 Q&A |
| `POST` | `/api/knowledge-base` | Массовое сохранение базы знаний |
| `POST` | `/api/knowledge-base/item` | Добавление или редактирование одного Q&A |
| `DELETE` | `/api/knowledge-base/item/:id` | Удаление вопроса по ID |
| `GET` | `/api/leads` | Получение списка заявок клиентов |
| `POST` | `/api/leads` | Создание новой заявки (с формы или AI-чата) |
| `POST` | `/api/leads/update-status` | Смена статуса заявки (`NEW`, `IN_PROGRESS`, `COMPLETED`, `CANCELLED`) |
| `POST` | `/api/manager-callback` | Эскалация дежурному менеджеру |
